# 家具比例調整記錄（v0.6 → v0.6.1）

## 回報問題
1. 整體家具看起來太小、高度太低（矮胖感）。
2. 茶几看起來懸空，桌腳沒有站在地上。

## 原因確認
1. **垂直被壓扁**：等角投影 `iso()` 的 z 原生 1:1，而格子在螢幕上是寬菱形，
   家具高度（z 2~3 單位）相對寬度（4~5 單位）天生顯矮。
   另 `footprint` 容器比例與本體比例不一致時，`preserveAspectRatio="meet"`
   會留白壓縮（例：v0.6 沙發 212×112 框只渲染出 112px 寬的圖）。
2. **懸空**：兩個疊加原因 —
   - CSS `.floor-shadow` 固定在容器 68% 高度，但桌腳底（z=0）落在圖的底部，
     陰影與腳對不上，中間出現空隙；
   - 茶几桌腳只有 0.28 單位粗、視覺支撐不足。

## 調整（warm-home/src/modules/furnitureArt.js）
- 新增 `Z_SCALE = 1.32`：投影時 `y = (x+y)*0.5 - z*1.32`，全家具等比拉高。
- 新增 `p.ground(cx, cy, r)`：在 z=0 地面畫等角接地橢圓（rx=r×0.866、ry=r×0.5），
  每件地板家具第一個繪製（墊底），陰影永遠跟著腳走。
- 茶几桌腳 0.28 → 0.34 加粗。
- `FurnitureItem.js` 移除對不準的 CSS `.floor-shadow`，只用圖內接地陰影。

## 尺寸公式（warm-home/src/modules/furniture.js）
`footprint.w = round((gw+gh) × 34)`，`footprint.h = round(w ÷ 本體實測比例)`。
本體比例以 `node aspect-tmp.mjs`（暫存腳本，用完即刪）實測 viewBox 得出：

| 家具 | 佔位 | 實測比例 | footprint（舊→新） |
|---|---|---|---|
| 床 | 4×3 | 1.039 | 210×194 → 238×229 |
| 沙發 | 3×1 | 0.929 | 120×122 → 136×146 |
| 書桌 | 3×1 | 0.953 | 120×120 → 136×143 |
| 植物 | 1×1 | 0.868 | 60×66 → 68×78 |
| 立燈 | 1×1 | 0.819 | 60×69 → 68×83 |
| 椅子 | 1×1 | 0.839 | 60×67 → 68×81 |
| 杯桌 | 1×1 | 0.824 | 60×67 → 68×83 |
| 搖椅 | 1×1 | 0.836 | 60×65 → 68×81 |
| 茶几 | 3×1 | 1.028 | 120×112 → 136×132 |
| 畫框 | 2×1 | 1.269 | 90×71 → 102×80 |
| 時鐘 | 1×1 | 1.000 | 60×60 → 68×68 |
| 窗戶 | 2×1 | 1.350 | 90×67 → 102×76 |
| 春聯 | 1×1 | 0.825 | 60×72 → 68×82 |

容器比例＝本體比例 → 本體 100% 填滿，不再留白縮小。

## 後續再調只需三步
1. 改 `DRAW` 裡該件家具 → 2. 跑暫存腳本量新比例 → 3. 按公式改該件 `footprint`。
   `Z_SCALE` 則是全域開關，動它之後 13 件比例都要重測。
